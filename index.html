Developer portfolio & DNS tooling

Small, non-commercial open-source tools for DNS, email authentication, domain research and repository security.

About

I build and document practical infrastructure tooling: DNS record checks, MX/SPF/DKIM/DMARC validation, abuse-contact discovery, and static audits of third-party repositories. The focus is on evidence: every conclusion should come from a reproducible check, not a guess.

Projects

offerlab

Collects free-domain offers from lists, forums and search, then scores them by DNS control, abuse contacts, card/KYC requirements and red flags. Includes proxy and Tor-aware fetching.

repoaudit

Static audit for GitHub repositories: binaries, install hooks, dangerous workflows, committed secrets and prompt-injection patterns — without executing third-party code.

Mail & DNS notes

Per-domain MX, SNI certificates, SPF, DKIM and DMARC on a self-hosted Mox server. Documentation covers repeatable setup and verification commands.

Domain research

Checks for free-domain services, delegation limits, abuse contacts and whether an offer actually works in practice rather than only on a landing page.
